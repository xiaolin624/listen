# Listen 术语表 (glossary)
#
# One term per line, UTF-8. Lines starting with '#' are comments; blank lines
# are ignored. The canonical spelling comes first, followed by optional aliases
# after a '|' separator:
#
#   Canonical Form | alias, alias, alias
#
# Matching is approximate and case-insensitive; spaces, '-' and punctuation
# between Latin words are ignored. Aliases may be a pinyin spelling
# ("shen du qiu suo") or a Chinese-character guess ("迪普西克"). They are
# compared exactly as written: there is no bundled hanzi -> pinyin table.
# The file is re-read when a capture starts, so edits apply to the next capture.
#
# Keep one entry per term. The canonical form alone already catches common
# mis-recognitions ("deep sea harnessness", "deep seek harness", "DeepSek
# harnessness", "deepsek", "waapp loop back", "wa-sa-pi"); spaces, '-' and case are
# normalized before matching. Aliases are only for what the matcher cannot infer:
# pinyin/Chinese spellings and short forms next to Chinese text.

# DeepSeek's harness product. "DeepSeek" itself is caught by the leading word,
# and the pinyin/Chinese spellings are what a user may add for their own audio.
DeepSeek Harness | shen du qiu suo, 迪普西克

# Windows audio APIs. "WASAPI loopback" already catches "waapp loop back" through
# approximate matching, so that spelling is not listed; the standalone "waapp"
# form keeps its alias because "WASAPI" is too short to match it approximately.
WASAPI | waapp
WASAPI loopback

# too short for approximate matching, so the measured short forms stay.

# T7：耳机播放路由变化与采集中断反馈

## Parent

[规格 Issue #1](https://github.com/xiaolin624/listen/issues/1)

## What to build

用户按同一套开始/停止操作，在实际耳机播放路径变化或中断时，工具能继续可靠获取正确音频，或明确反馈本次采集中断并保留已接收内容。用户无需选择会议应用或理解不同程序的音频来源。

本任务覆盖原型尚未验证的默认通信与多媒体设备分离、应用单独路由、设备断开和中途切换；不能把只抓到另一个默认设备的声音当成已经完成耳机采集。

## Acceptance criteria

- [ ] 在实际耳机播放路径上验证采集范围，涵盖默认通信与多媒体设备不同、应用单独路由等条件；不得以按会议软件筛选来缩小已确认范围。
- [ ] 能可靠识别并跟随设备变化时继续采集；无法确定或保持正确路径时，明确反馈中断，避免继续显示一切正常。
- [ ] 设备断开或路由中断后保留已有音频或可恢复结果，用户可得到清楚标明状态的当前结果，不将不完整内容冒充完整采集。
- [ ] 不主动开启麦克风，不误把其他播放设备的音频声明为用户耳机正在听到的内容。
- [ ] 通过既有结果交付入口完成设备变化的端到端验收；没有自动回填时可用备用文本框，不依赖回填任务完成。
- [ ] 对实际硬件可覆盖的场景给出实机证据，其余事件处理使用可控环境复现并明确标注；未实测的耳机类型或系统配置不宣称已经通过。

## Blocked by

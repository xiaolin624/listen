# T1：快捷键采集耳机音频并得到可复制的本地转写

## Parent

[规格 Issue #1](https://github.com/xiaolin624/listen/issues/1)

## What to build

在本地模型和可用后端已准备的条件下，交付可运行的 Windows 后台工具：按全局快捷键开始采集当前耳机音频，再按一次停止，将其中的语音在本机转写，并在备用文本框中显示当前结果供复制。

本任务跑通真实音频、真实本地识别和可见结果的最小完整流程，同时建立其他任务沿用的应用控制与状态入口。应用实现优先考虑 Rust。现有实验是可参考的证据，不等于正式工具已经存在。

阶段演示以已知短语音为样本，不引入产品固定时长上限；长时间分段和压力验证由后续任务扩展。自动回填由后续任务接入。

## Acceptance criteria

- [ ] 用户可启动后台工具，并用全局快捷键完成一次开始和停止；有就绪、采集中、处理中和失败等必要状态，正常采集不持续显示字幕。
- [ ] 直接采集播放设备上的耳机音频，不要求选择会议应用；至少以不同应用播放的已知语音检验来源范围，且工具未主动开启麦克风。
- [ ] 停止后通过真实本地识别得到结果，在备用文本框中完整显示并可复制；本地模型已准备时可断网完成该流程。
- [ ] 全流程不自动发送消息、不调用大模型或 agent 的发送接口，不把转写文字当作操作执行。
- [ ] 当前结果可供查看和复制；成功转写后清理本次临时音频，识别失败时保留音频并明确反馈，不默默改用云端识别。
- [ ] 快捷键无法注册、播放端无法打开或本地后端不可用时，状态明确，不能假装已经正常采集或识别。
- [ ] 演示和集成验证使用真实播放音频和本地模型；逻辑故障可用可控外部依赖复现，并从同一开始/停止入口检查最终行为。
- [ ] 本任务没有增加固定分钟数限制；交付说明如实标明尚未完成长时间采集、实际编辑区回填和性能优化的验证。

# T8：普通话、中英混合及无语音场景的本地识别质量

## Parent

[规格 Issue #1](https://github.com/xiaolin624/listen/issues/1)

## What to build

将基于已知音频对照选择的本地识别方案接入实际采集到结果的流程，覆盖普通话、英文单词和技术词，并处理没有有效语音时不应输出发言的情形。结果保留说话内容，不改写成摘要。

现有 base 模型仅证明本地推理可运行，实验中有繁体输出和同音错字。本任务形成可复核的质量基线和默认方案，作为后续性能优化的对照；不擅自承诺逐字零错误或尚未约定的准确率百分比。

## Acceptance criteria

- [ ] 用已知文本的普通话、中英混合、英文技术词及数字样本运行完整采集到结果流程；记录人工对照、遗漏和错字，而非只检查输出非空。
- [ ] 将评测选定的本地模型与解码设置接入默认实际流程，记录选择依据、仍有的错误和可复核条件。
- [ ] 已知“本机/本季”等易错内容和中文繁简输出纳入对照；明确中文输出处理策略，不通过总结或改变发言含义掩盖错误。
- [ ] 对静音、无语音的音乐和提示音进行验证，没有有效语音时不向目标或备用文本框输出凭空生成的发言，状态明确。
- [ ] 识别包含英文术语、数字及多行内容时，交付的仍是原发言的转写结果，由用户检查并手动发送。
- [ ] 本地模型准备好后可断网完成上述验证，不把模型失败或质量问题交给云端服务处理。
- [ ] 形成固定、可重复的质量样本和默认配置，供后续加速对照使用；实际质量限制如实报告，不将合成语音单样本等同于真实会议表现。

## Blocked by

- T1：需要真实采集、本地识别及可见结果的完整使用流程。

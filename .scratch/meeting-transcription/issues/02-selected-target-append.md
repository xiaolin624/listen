# T2：向预先选定的原生输入框追加转写文本

## Parent

[规格 Issue #1](https://github.com/xiaolin624/listen/issues/1)

## What to build

用户先点击或双击目标输入框，再按快捷键开始采集。工具在改变焦点之前记住本次明确选定的目标，停止后把真实转写结果追加到该目标的最新内容末尾；用户自己检查并发送。

先以原生可编辑控件完成真实的目标选择、采集、停止及回填路径，并沿用已有备用文本框。通用桌面和网页编辑区扩展由后续任务交付。

## Acceptance criteria

- [ ] 从用户实际选定的编辑区获取目标，不通过硬编码控件句柄、坐标或要求用户选择应用类型来代替目标选择。
- [ ] 开始后切换窗口或焦点，停止时仍只向本次原目标输出，其他输入框内容不变。
- [ ] 读取并保留输出前的最新原文，将转写文本追加到末尾；采集期间用户新增的编辑仍保留。
- [ ] 中文、英文、数字和多行结果完整保留；本次输出只追加一次，发送动作始终由用户完成。
- [ ] 无有效目标、原目标已失效或无法确认基本写入结果时，保留完整转写文本到备用文本框，不自动换投其他控件。
- [ ] 通过全局快捷键和真实本地识别演示完整流程；现有仅以测试句柄取得控件的实验不能替代该验收。
- [ ] 从已确认的完整流程测试入口覆盖目标锁定、切窗、最新原文保留、追加结果及没有发送动作。

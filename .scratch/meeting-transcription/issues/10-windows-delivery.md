# T10：Windows 可运行交付包与整体验收

## Parent

[规格 Issue #1](https://github.com/xiaolin624/listen/issues/1)

## What to build

交付用户能按说明启动的 Windows 应用包，明确本地模型准备和运行条件，并用完整真实使用流程验证各项能力已经组合起来：选中输入框、快捷键开始/停止、耳机音频本地转写、追加原框或备用复制、手动发送。

本任务完成最终可用交付和父规格的整体验收，不自动建立历史、不引入云端识别或自动发送。已有各分支能力必须在同一交付版本中工作，而非分别存在于实验程序中。

## Acceptance criteria

- [ ] 提供可运行的 Windows 应用包和必要的本地模型准备说明，明确模型/运行库缺失时的反馈；正常使用不要求用户分别启动开发脚本或独立推理命令。
- [ ] 本地模型已准备后断网，从启动、选定目标、开始到停止和结果交付完成真实使用流程，整个识别保持本地运行。
- [ ] 在实际可覆盖的耳机和桌面/网页编辑区完成集成验收，记录已通过和受平台限制的情况；用户操作不需要应用类型或声音来源应用选择。
- [ ] 共同验证原文和新增编辑保留、完整追加、无自动发送，以及目标失效、写入不确定和超长结果时的备用输出。
- [ ] 验证失败重试、成功清理、无自动历史、设备中断和恢复反馈，以及长时间采集和资源受压行为。
- [ ] 汇总首次及后续端到端延迟、长会话收尾、资源占用和实际识别质量；测试样例时长不变成产品上限。
- [ ] 所有验收沿已确认的应用使用入口完成，提供可复核结果，不能用技术验证程序的单项成功代替交付应用的整体验收。
- [ ] 发布说明保持父规格范围，明确尚存平台限制，不宣称任意控件无条件可写或任意会议逐字零错误。

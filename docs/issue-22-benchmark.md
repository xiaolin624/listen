## Notes

- `Chinese accuracy` is 1 - (sum edit distance / sum reference characters) after removing punctuation, symbols and spaces. Recognition failures and no-speech count as all characters wrong; the aggregate is clamped at 0 while per-sentence CER is not.
- `stop->result` is `timing_stop_to_result_ms` reported by Listen; the wall-clock column also includes control-process latency.
- The engine label is operator supplied in attached mode; the app's own `backend=` note is stored with every sample in the JSON results.
- The corpus was recorded through the Tencent-Meeting link; playback during this benchmark uses the default multimedia render endpoint, not the meeting application.

# 主界面改为常驻状态胶囊，删除详情窗口

状态：accepted（2026-11-12）

工具在后台时用户看不见它是否在运行；现有主窗口（状态文本、备用文本框、五个按钮）操作成本高。决定：主界面改为常驻桌面、置顶但不抢焦点、不进入任务栏的长条“状态胶囊”，不显示文字、数字或实时转写，只用颜色、形状与动效表达就绪/采集中/处理中/失败；点击展开为文本面板；没有目标输入框时，转写结果直接在该面板显示与复制；删除原详情窗口；胶囊用 `WDA_EXCLUDEFROMCAPTURE` 对所有屏幕共享与录屏隐身；不引入历史记录。

## 后果

- 现有桌面验收脚本依赖 `ListenCaptureToCopyWindowV1` 与控件 ID，需要改为通过 `--control`、`status.txt` 和胶囊展开面板验收。
- 托盘菜单保留退出、重试、清理；精修入口放在展开面板。

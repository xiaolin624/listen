# 默认全本地，精修只把文字发到 DeepSeek API

状态：accepted（2026-11-12）

Wispr 级别的准确率依赖云端大模型加 LLM 改写，但把会议里其他人的音频上传云端有隐私与合规风险，而且不会更快：本地常驻模型约 0.5 秒，云链路估算 1.5–3 秒。决定：默认全本地；用户手动触发“精修”，只把文字（不含音频）发给 DeepSeek API；精修结果在目标内容仍等于刚插入的原文时直接替换，否则放进展开面板、不覆盖用户编辑；API key 只存本机凭据。

## 后果

- 精修需要网络、API 费用和失败回退；网络不可用时保持本地结果。
- 精修无法救回本地 ASR 没有听出的词，只能修“看起来像”的专名与标点。
- 音频始终不出本机；这条边界不随精修改变。

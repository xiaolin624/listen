# 验收通过后把云端设为日常默认，本地改为显式备用

状态：accepted（2026-11-21）

#40 的放行门槛是同一批 20 段真实音频的准确率、延迟与恢复验收。2026-11-21 的单厂商验收（[`docs/issue-40-acceptance-20261121.md`](../issue-40-acceptance-20261121.md)）在同一批冻结语料、真实应用工作流和真实阿里云百炼北京 Message 路径上给出：交付 20/20，停止到结果可见中位 656 ms、最慢 844 ms（20/20 ≤ 1 秒），聚合准确率 95.86%（CER 4.14%），相对同一批音频的本地 SenseVoice 基线 75.39% 错误下降 83.2%；每次开始前现场只读核验唯一默认工作空间、精确型号、额度与 `autoStop`。决定：日常默认切到这一个已验收的云端路径（阿里云百炼 `qwen-audio-3.1-asr-flash-message` / `cn-beijing`），本地识别保留为**显式备用**（`--engine` 或包内本地备用启动器）；二者在一个任务内不能组合，也不存在云端失败后的自动本地替代。

## 后果

- 默认启动需要本机凭据、工作空间、固定型号/地域和免费保护。缺任一项时开始采集被拒绝，状态给出可操作的修正原因，已收到的音频保留；不写目标，也不静默改成本地识别。
- 状态与面板必须写明实际来源：`recognition_mode=cloud-trial|local` 与 `backend=`。本地是显式选择，不是失败降级；本地模式不读取云端运行目录的待处理音频。
- 费用语义沿用 #37：共享 CNY 50 首轮账本、每次请求前的实时免费保护核验、未知用量不记为 0；CNY 100/月只是提醒线，不会自动购买套餐、提高预算或扩大额度。免费额度到 **2026-12-21**，之后按厂商实际计费转为付费。
- 交付包默认启动器走云端，另提供明确标注的本地备用启动器与独立运行目录；manifest 记录 `default_mode=cloud`，打包验证同时检查两条路径的实际来源。
- 验收只覆盖单厂商与受控编辑框夹具；现金账单对账、留存/训练条款的独立核实、真实弱网演练仍未完成。相关文档不得据此声称零留存或账单为 0。
